# Assessment follow-up: brief and implementation

Route: `/assessment-follow-up`. Teacher task: import a reusable assessment mapping and class QLA, choose defaults, generate one printable class PDF without AI or a mandatory review step. Pupil task: complete practice linked to an assessment question, then use the complete upside-down scheme.

## Scope and contracts

- Inputs: browser-only XLSX/CSV/TSV or pasted cells, up to 500 pupil rows and 300 columns. Results headers and identifiers are optional. Detect recognised headers, or use assessment order with an optional first identifier column; entirely numeric question-width data remains marks. Structured blank pasted rows retain absent pupils. Adjust import can override headers, identifiers and the first question column. XLSX sheets are selectable. Formula cells are not calculated. No uploads, pupil storage, analytics, logs or pupil URLs. State survives section navigation during the session and is cleared on reset/reload. Only assessment mappings can be downloaded for reuse; no pupil JSON export or recovery key.
- Student identifier column is selectable. Blank identifiers get S001 etc. Names are discouraged, not rejected; duplicate identifiers are disambiguated. Year (7–13), tier F/H and strength developing/secure/strong optionally override class defaults.
- Whole-question or part mappings can be populated from an existing paper. Separate part scores (1a, 1b, etc.) are the default, including after reset and in the anonymous example; untick for whole-question totals. Custom CSV headers: Question, Max marks, Sparx codes, optional Question ID. A code cell accepts multiple codes separated by spaces, commas or semicolons; all contribute to topic priorities and practice questions are deduplicated. A whole-question score cannot distinguish which of its mapped skills caused lost marks. Known original IDs and crossover equivalents are excluded. Without a source ID, the assessment's provenance cannot be inferred.
- Approved HPP1–6 and MM1–3 at both tiers are independent assessment presets, exported from the current print-ready manifest and read-only source mappings using the current Sparx policy. All 18 totals and part sums are verified, with MM1 Higher at 55. Six full HPP1-2, HPP3-4 and HPP5-6 presets combine the complementary selections at both tiers; each totals 80 marks, retaining original question and part order and source IDs. Presets include known source IDs even when those questions are absent from the published practice bank; no source questions or PDFs are republished. Rebuild metadata with `scripts/import-assessment-presets.py --workspace <workspace>`. The generated file contains metadata only and no pupil information.
- Missing/absent is not zero. Out-of-range scores become missing, with row-number-only notices. Unknown mappings are skipped. Stable selection orders make the same data reproducible.
- Topic priorities pool recorded marks for the same code within one original question, including correct parts; blanks contribute no evidence. Shared-code rows divide marks between codes. Distinct original questions can contribute separate evidence. Lost-mark proportion and capped mark size are multiplied by `0.15 + 0.85 × (1 − original assessment position)²` before choosing topics. Position uses the original exam count where available, otherwise the largest numeric assessment label; spreadsheet order never determines difficulty. Unknown labels use a neutral midpoint. Keep all priorities until at least one complete practice question and scheme fits, then focus on the first three available skills. A wholly correct record does not become an assumed all-zero record.
- Practice candidates are weighted by matched-mark relevance, measured/estimated accessibility and source-paper position. Percentage bands developing 70–100, secure 55–80 and strong 0–65 are preferences, adjusted for year and topic support. Estimates use the same support band, with lower weight on position; labels explicitly distinguish estimates from exam averages. Tier-specific appearances provide tier-specific percentages. These heuristics do not infer prerequisites or guarantee individual success.
- Individual packs cover each available priority skill before repeating a skill where space allows. Complete questions and schemes only. Missing pupils use common selections; common mode gives exactly one set to everyone, with class settings. A wholly absent class uses assessment topics. Per-pupil overrides can adapt individual missing-pupil fallback to a different tier. Partial records receive class-common supplementation only for unrecorded topics, preserving demonstrated success.
- Optional collapsed **Not yet taught** checkboxes group assessment parts by original question. Selected groups exclude all their mapped codes throughout individual/common/absent selection, including practice questions that mix excluded and allowed codes. Import columns and original/crossover exclusions stay intact. Changing assessment or resetting clears exclusions; switching parts/totals within an assessment retains them. No topics are assumed untaught automatically.
- Defaults: Year 10, Higher, secure, four A4 pages, marks off, individual mode. Page options 1/2/4/8; marks cap 1–200; either or both constraints may apply. Selection is bounded at 60 questions per pupil. No filler or exact-mark promise.
- Export uses normal A4 points, complete question/context images and working space. Answers come after questions, entire blocks rotated 180 degrees, conservatively scaled with a 0.66 minimum. Existing physical-scale questions remain 1:1. Full references and source notes participate in layout. Invalid/oversized candidates are skipped. No teacher UI furniture in pupil output.
- Page-mode packs reserve exactly N pages, including answer space and padding; marks-only packs have variable length. One class PDF in imported order; each pupil starts a new page. One-page packs should print single-sided. Duplex/n-up/booklet imposition is delegated to PDF software. Physical print checking remains a human release check.
- Class view leads with the actual question/mark ranges and highlights zero-question packs. Pupil selection and Previous/Next page controls keep preview navigation local. Both download buttons reference the same class Blob, including the button immediately below the preview. Generate is highlighted before generation; once a PDF is ready both Download buttons are highlighted and Generate is secondary. Editing inputs invalidates the download with an explicit regeneration notice and restores Generate emphasis; reset restores the initial state. Mapping and print details remain collapsed for preset use.
- Simplified preview: initial Choose an assessment placeholder hides the custom mapping editor until explicitly selected. Paste marks is the primary input; spreadsheet upload and template download are alternatives below it. The example contains marks only, including a structured blank row for the absent student, and creates S001/S002/S003. Visible feedback reports students and matched columns, with missing counts only when nonzero; missing columns and invalid scores remain prominent. Detection assumptions and corrections sit inside Adjust import. Year, tier, strength, pages and common mode stay visible; calculator, mark limits and selection explanations sit in More options. Student details, printing guidance and privacy information are collapsed. Selection, PDF contents and identifiers supplied by teachers retain their existing behaviour.
- The shared layout calculation supplies both selector and renderer. Export verifies asset dimensions against reviewed catalogue metadata and returns no partial PDF after asset failure/cancellation.

## Reference examples and acceptance

1. Zero-score pupil, partial-score pupil and absent pupil on November 2019 1H: individual practice, common fallback, original/crossover exclusion and matched schemes.
2. One/two/four/eight A4 allocations with answers inside each limit; marks-only and combined constraints.
3. Entire class absent, common-set mode and pupil tier/year/strength overrides.
4. Invalid mappings/scores, duplicate/blank identifiers, long references, source errata and scale-sensitive questions.
5. Real XLSX selection and CSV/paste import, reset/reload privacy, navigation retention, keyboard controls and 320px layout.
6. Complete actual PDF assets, inverted answer blocks, no clipping, no cross-pupil content and expected page count.

This is a question-bank workflow, not a mathematical diagram editor: Word clipboard/SVG exports, diagram undo, saved pupil files and MCP access are deliberately outside scope. Existing diagram tools, files, assets, branding and service definitions are preserved.
