# Number lines

Open https://mathsdock.co.uk/tools/number-line. The website editor works
independently of the optional MCP service.

Choose Point, Interval or Ray and click ticks. Click a circle to switch between
filled (included) and hollow (excluded). The selected endpoint shows its exact
value and type; rays additionally show direction. Tab focuses without changing
type; Enter/Space toggles it. Drag endpoints to ticks or use arrow keys for step
movement. A drag moves once without changing type. Exact decimals/fractions
remain editable. Enter/blur applies valid input; Escape restores it. Invalid
drafts block conflicting actions and exports, and their settings stay open until
corrected/cancelled. Range shortening never silently deletes finite endpoints.

Join existing points: choose Interval and click the two points (or ticks).
Those clicks join without toggling type; other points and their appearance
remain. In Point mode, empty ticks add points and existing circles toggle type.
Select a connecting line and choose Remove interval to retain both endpoints.
Removing a point also removes its attached intervals; the button states this,
and Undo restores everything.

Draw and Scale stay visible. More settings groups Labels, Question and answer,
Print size, Manage drawing and Help in closed subsections. Optional contents,
pupil blanks and hidden answers survive closing/reopening. Examples opens one
past-paper chooser with source/scaffold and worked actions. Only the selected
endpoint, tick or variable shows contextual controls.
Past-paper examples offer source/scaffold and explicit worked choices. Read
questions retain their shown drawing with an unanswered response. Nadia's ray
is intentionally incomplete; its corrected version is a separate action.
Changing presentation/print width does not calculate or fill answers.

Editable envelope: schemaVersion 1, rendererVersion number-line-1, styleProfile
examination-v1, kind number-line, document. Document contains axis, solution,
teaching and widthCm. Numeric mathematical inputs are exact strings. axis has
minimum, maximum, step, labelEvery, variable, variableBelow and numberFormat
(decimal where exact or fraction). A solution is null, an interval, ray or
discrete points. teaching retains labels, solutionVisible, prompt, answer,
answerVisible and responseLines. Labels use canonical rational-value keys.

Saved-file recovery protects original corrupt/newer-tab data before a fresh
start. Use Copy to clipboard for an image or Copy for Word for physical-size
HTML. Actual browser downloads provide SVG with embedded portable fonts,
verified 600 ppi PNG and editable JSON. Preview zoom changes the view only.
Print size is independent.

This website release does not deploy or refresh the separate MCP service/client.
Publication uses docs/release/RELEASE-PIPELINE.md and its exact qualified artifact.
