Planning, sequencing and producing resources for Years 7–11

Version 1.2 \| 18 October 2026 \| PLAN, FINALISE and PRODUCE workflow
templates

| **Design for what pupils should notice, not just what they should calculate.** |
|--------------------------------------------------------------------------------|

Use this guide when planning or revising worksheets, booklets and
projected practice. It brings together Tim’s recorded feedback, the
discussion of Craig Barton’s intelligently varied practice, and
practical applications developed from that discussion. \[1, 2\]

## The core standard

| **Design decision** | **Default approach**                                                                                   |
|---------------------|--------------------------------------------------------------------------------------------------------|
| **Purpose**         | Identify prerequisites, the intended insight and likely misconceptions before writing questions.       |
| **Sequence**        | Establish familiar cases. Use short, purposeful chains when comparison will reveal useful mathematics. |
| **Challenge**       | Plan mathematical difficulty, presentation changes and scaffold fading separately.                     |
| **Independence**    | Move towards mixed practice without neighbouring examples or unnecessary support.                      |
| **Presentation**    | Keep pupil text concise; provide the space, notation and diagrams needed for full working.             |
| **Production**      | Preserve approved content. Check answers, diagrams, layout and page versions before delivery.          |

## How to apply the guide

Treat these as design defaults, not a compulsory lesson structure. Apply
the sections relevant to the current resource. A request for six
mini-whiteboard questions does not require a full booklet; a
declarative-only knowledge organiser does not need a practice sequence.

For resource-design choices, follow Tim’s current explicit request and
latest approved corrections rather than conflicting defaults or older
examples. Flag substantive conflicts instead of silently changing
approved content. Do not infer a class’s needs solely from its year
group or tier.

## What the evidence labels mean

**Recorded feedback** reports what Tim said or requested. **Illustrative
application** is a proposed way to use the principles, not a claim that
it has been trialled successfully. Barton’s article is a practitioner
account, not a controlled evaluation of this guide. \[1, 2\]

Navigation: planning · challenge and scaffolding · comparison examples ·
representations · production · feedback register · final checks ·
maintenance and sources · workflow commands and templates (Appendix A).

01 / PLANNING

# Start with the mathematics

Before generating questions, establish the class and attainment,
learning objective, relevant prior teaching, intended task type,
calculator expectations and requested format. Use information already
supplied. Where a minor detail is missing, state a reasonable assumption
rather than restarting the brief.

## What the teacher-facing plan should show

| **Planning question**                 | **What to specify**                                                                                              |
|---------------------------------------|------------------------------------------------------------------------------------------------------------------|
| **What must pupils already know?**    | Name the prerequisite facts and procedures. Include a short check or a bridge only where it is needed.           |
| **What should pupils notice?**        | State the mathematical insight, not just the instruction “practise the method”.                                  |
| **What might go wrong?**              | Identify the relevant misconception or entry difficulty, using known class feedback where available.             |
| **What stays the same and changes?**  | Choose examples around the insight. Explain why the selected change matters.                                     |
| **How will support fade?**            | Identify the representation, partial working or prompt retained at each stage and the point of independent work. |
| **How will independence be checked?** | Include a task that cannot be completed simply by copying the previous example’s pattern.                        |

## Use short chains, with deliberate resets

Barton describes beginning with the range of ideas, critical features
and misconceptions, then using several short chains rather than tying
the whole resource to one starting example. A fresh chain can return to
an accessible case before introducing a different feature. \[2\]

A suitable structure might be: **familiar method → focused comparison →
a fresh chain for a new feature → mixed independent practice**. The
number of chains and questions should follow the content and available
working space, not a fixed quota.

## Choose numbers for a reason

During a focused comparison, select numbers that expose the intended
relationship without adding unplanned arithmetic difficulty. Later, vary
irrelevant details to check that pupils have not learned a superficial
pattern. Not every adjacent question needs to be minimally different.

| **Planning format:** Section or questions \| intended insight \| what stays constant / changes \| support retained / removed \| independent check. |
|----------------------------------------------------------------------------------------------------------------------------------------------------|

## Avoid a disguised difficulty ladder

Larger numbers, more negative signs or denser wording do not by
themselves create a worthwhile progression. Decide whether each new
demand develops the target mathematics or merely makes the calculation
longer. Keep the detailed rationale off the pupil sheet.

02 / CHALLENGE AND SUPPORT

# Manage difficulty and scaffold fading

The following separation is a practical application developed in this
discussion. It responds to Tim’s feedback about unfamiliar early
questions and the need for support to fade without disappearing too
soon. \[1\]

| **Demand**       | **Examples of a change**                                                       | **Default response**                                                             |
|------------------|--------------------------------------------------------------------------------|----------------------------------------------------------------------------------|
| **Mathematics**  | Positive to negative gradient; integer to fraction; direct to reverse problem. | Retain familiar wording and useful support while the new feature is established. |
| **Presentation** | A new graph scale, rotated diagram, context or representation.                 | Initially use familiar mathematics so the new presentation is the main demand.   |
| **Support**      | A ratio table, grid, marked point or partial solution disappears.              | Remove support first on mathematics pupils have already met successfully.        |

## A flexible fading sequence

| **Stage**                | **What pupils do**                                         | **Design requirement**                                                  |
|--------------------------|------------------------------------------------------------|-------------------------------------------------------------------------|
| **Model / our turn**     | Follow or complete the method with the teacher.            | Use the representation they will encounter in independent practice.     |
| **Supported practice**   | Complete a grid, ratio table or partly worked calculation. | Leave genuine decisions; do not make every answer a transcription task. |
| **Reduced support**      | Use a blank structure or one short prompt.                 | Keep the mathematics familiar while the support is reduced.             |
| **Independent practice** | Choose and record the method without the structure.        | Leave enough blank space for the full working, not just the answer.     |

Do not attach these stages to fixed question numbers for every class.
Give enough straightforward practice before less standard questions. A
later mixed task can deliberately combine demands once the component
ideas are secure.

## Change the task when another calculation will not help

Where pupils struggle to begin, consider matching an expression to a
completed grid, choosing between methods, completing one missing part or
correcting a specific error. Return to constructing the solution
independently; success in matching alone is not the final check.

## Independence after the pattern

Finish a practice sequence with mixed questions where earlier examples
no longer supply the answer structure. Where useful, plan a later
starter with fresh numbers or presentation. Do not leave section labels
or method hints that defeat an intended method-selection task.

| **Check each transition:** Have we changed the mathematics, changed the presentation and removed support at once? Where this is deliberate, make its purpose clear in the teacher plan. |
|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|

03 / PURPOSEFUL COMPARISON

# Make the relationship visible

Barton’s reflect–expect–check–explain approach asks pupils to consider
the change, predict its effect, calculate and then explain. Use selected
spoken or projected prompts rather than requiring a written explanation
after every calculation. \[2\]

## Example A: triangle area

**Design-brief exemplar.** Tim requested four different triangles, all
with base 6 and perpendicular height 4. This is a recorded design
intention; it is not recorded here as evidence of a successful lesson.
\[1\]

| **Keep constant**                  | **Vary deliberately**                                                     | **Intended insight**                                      |
|------------------------------------|---------------------------------------------------------------------------|-----------------------------------------------------------|
| Base 6 and perpendicular height 4. | The position of the third vertex, so the triangles have different shapes. | Area remains 12 square units despite the change in shape. |

Keep the base and height clearly identifiable. Do not accidentally
replace perpendicular height with a sloping side. Introduce an external
height separately if recognising it would create an additional
challenge.

| **Pupil prompt:** Before calculating the next area, predict whether it will be larger, smaller or the same. Which measurements matter? |
|----------------------------------------------------------------------------------------------------------------------------------------|

## Example B: factorising with a negative constant

**Illustrative application, not a previously trialled resource.** The
pair below was proposed in this discussion to focus attention on the
signs of the factors.

> $x²\  + \ 2x\  - \ 15\  = \ (x\  + \ 5)(x\  - \ 3)$
>
> $x²\  - \ 2x\  - \ 15\  = \ (x\  + \ 3)(x\  - \ 5)$

The product stays at −15 and the absolute values remain 3 and 5.
Reversing which number is negative changes the sum from +2 to −2. For
pupils not ready to factorise independently, begin by matching completed
grids to the expressions, then remove that support.

| **Pupil prompt:** The constant term has not changed. What must change in the grid to make the middle term negative? |
|---------------------------------------------------------------------------------------------------------------------|

## Arrange the questions to support the comparison

Keep a useful pair adjacent, rather than across a page turn or distant
columns. For projected examples, showing the previous question alongside
the current one can make the comparison explicit. Keep graph scales and
visual conventions stable unless changing them is the point. \[2\]

After a focused pair or chain, use a fresh question without the matching
neighbour. Comparison should prepare pupils for independent mathematics,
not replace it.

04 / REPRESENTATIONS

# Notation, diagrams and working space

## Ratio tables and gradients

Use Tim’s established ratio-table conventions where relevant:
mathematical italic x and y, distinct from the multiplication sign ×;
headings x → and y ↑; clear entries and a genuinely blank answer space.
Do not reintroduce decorative downward arrows. \[1\]

| *x* → | *y* ↑            |
|-------|------------------|
| 4     | 8                |
| 1     | \_\_\_\_\_\_\_\_ |

In a gradient movement table, the entries represent changes in x and y,
not a point’s coordinates. Label a coordinate/value table appropriately
when that is the intended representation. Do not blur the two meanings.

## Coordinate grids

Provide grids tall and spacious enough for pupils to label axes and show
their working. Keep tick labels clear, and check the scale on each axis.
Add room without accidentally stretching one axis or changing the
intended unit geometry. Use labelled changes rather than visual
steepness when axes have different scales.

Where movement triangles are used, put the horizontal change by the
horizontal leg and the vertical change by the vertical leg. Avoid a
layout that suggests pupils should calculate the diagonal distance. Fade
marked points, movement triangles and tables deliberately. \[1\]

## Work down the page

Provide a new line for each stage of working, generally with one equals
sign per line. Use horizontal fraction bars in worked examples and
fading scaffolds rather than inline slash notation. \[1\]

> $A\  = \ \frac{6\  \times \ 4}{2}$
>
> $A\  = \ \frac{24}{2}$
>
> $A\  = \ 12$

The final independent questions need blank working space, not
permanently printed denominator bars. Keep the final answer area
distinct from the working where it helps pupils organise their solution.

## Geometry and diagrams

Attach each label unambiguously to the correct side, angle or point.
Show perpendicular heights and right-angle markings where needed. Check
that the diagram and question agree and that labels do not collide.
Preserve approved grid methods and diagram conventions when revising an
existing resource.

## Shared information and reminder cards

Use one consistent visual convention for shared information and
reminders, whether an experiment diagram, repeated data, a definition or
a short notation cue. Repeat useful information near the questions that
need it, including midway through a sequence. Use a very pale tint of
the surrounding section’s accent colour (not always blue); omit
question-number badges and prominent borders. Keep wording, diagram
proportions, typography and spacing consistent, with sufficient
greyscale contrast. These cards should reduce the need to search
backwards or remember details, rather than add decoration.

05 / PRODUCTION

# Produce a clean, consistent resource

## Choose the format from the brief

| **Resource**           | **Usual approach, unless the request says otherwise**                                                                                            |
|------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------|
| **Write-on worksheet** | Double-sided A3 landscape is a frequent preference, with narrow practical margins and generous working space. It is not a universal requirement. |
| **Booklet**            | Use the requested page size, orientation and page count. Keep the normal reading order; do not impose printer spreads unless requested.          |
| **Projected practice** | Use 16:9 when requested. A 3-by-2 arrangement suits a specified set of six questions, not every activity.                                        |
| **Existing resource**  | Preserve its approved style, colours and structure when asked. Do not impose a new template during a limited correction.                         |

## Use space for the work pupils must actually do

Prefer concise UK mathematics wording, clear numbering and purposeful
headings. Avoid decorative images, excessive explanation, unnecessary
branding and repeated generic instructions. Use high-contrast text and
check that required features survive monochrome printing unless colour
is explicitly part of the brief. \[1\]

Allocate space by task: a calculation needs vertical working room; a
construction needs an open drawing area. Keep questions, diagrams and
their working spaces together. Do not shrink text to force everything
onto a fixed page. Reflow first; propose any necessary content reduction
rather than silently deleting questions.

## Vector-first final worksheets

For resources requested as vector PDFs, use real text and vector lines,
diagrams and borders. Placing a screenshot inside a PDF or enlarging an
image does not make it vector. If the only starting point is an image,
rebuild the approved content rather than simply upscaling it. \[1\] For
PDF corrections, revise and regenerate the original source: never mask
old content with white patches, replacement cards or other overlays. If
source is unavailable, reconstruct the affected section using native
vector elements.

Inspect the final page at its intended print size and zoom in to check
sharpness, alignment and clipping. Check both sides separately; matching
filenames alone do not establish that they are the latest approved
pages.

## Protect approved content and rebuild revisions cleanly

Keep one approved question set as the basis for the pupil sheet, answers
and projected material. When revising, record the requested changes and
protect everything else. If a mathematical error is discovered, flag and
correct it explicitly rather than preserving it unnoticed. Reflow
changed content, inspect every affected page against the approved
original, and flag any case where a faithful source-level rebuild is not
feasible.

| **Before combining pages:** identify the latest approved front and back, their first and last question numbers, and the latest corrections. Then verify those features in the combined file. |
|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|

Keep production notes and file versions separate from pupil-facing
content. Do not add page or version numbers to resources intended for
mixing and matching when Tim has asked for them to be omitted. Do not
reveal answers on pupil-facing versions unless requested.

06 / FEEDBACK REGISTER

# Use the classroom feedback precisely

These entries summarise Tim’s briefs and reported feedback. They are not
substitutes for the original approved files: reopen the relevant
exemplar before copying its exact layout. The status of a suggested
response is kept separate from the observed problem. \[1\]

## Year 10 · straight-line booklet

**Recorded classroom feedback.** Pupils needed more straightforward,
familiar questions before less standard ones. An early unfamiliar
question was difficult; supporting ratio tables using 1 and 4 for x were
requested. Early questions requiring both intercepts were to be removed.
A positive fractional-gradient question was to come before a
negative-gradient question, and a later section needed a
positive-gradient starting example.

**Carry forward.** Start with recognisable cases, retain useful support
during a new demand and provide taller grids with separate working and
answer spaces. Do not turn this into a universal claim that fractions
are easier than negative numbers; use the actual class and question
demands.

## Year 9 · quadratic factorising

**Recorded difficulty and proposed direction.** Pupils found factorising
with a negative constant difficult. Tim proposed selecting or matching
correct grids, and a prerequisite sequence with numbers first and then
algebra. These are recorded as planned responses, not as proven
improvements.

**Carry forward.** Check signed multiplication, signed addition and
selecting a pair with the required product and sum. Preserve the
familiar grid method. Use matching or completion to isolate the
obstacle, then return to independent factorisation. Do not respond only
by generating more questions at the same level.

## Year 8 · triangle area and sample spaces

**Recorded design and layout requests.** Triangle-area work should begin
with four different triangles sharing base 6 and perpendicular height 4,
with “over 2” scaffolding that eventually fades. In sample-space work,
an earlier layout was too verbose and had too much generic writing
space; pupils needed room to draw diagrams, with pre-drawn tables
positioned after the first question that required them.

**Carry forward.** Allocate space to the intended pupil action. Preserve
the timing of scaffold introduction as well as its appearance. Inspect
table dimensions and category labels; do not introduce an extra row or
column during redrawing.

## Year 11 · trigonometry and cosine-rule resources

**Recorded production feedback.** Tim requested vector text and
diagrams, larger text on a front sheet and reliable combination of the
latest approved front and back. Earlier outputs sometimes used an old
back sheet or mixed a raster front with a vector back.

**Carry forward.** Treat page identity and legibility as separate checks
from mathematical accuracy. Rebuilding or combining pages is not
permission to alter the approved questions, labels or order.

| **Generalise cautiously:** retain a lesson about design when it transfers; retain a specific question change with its original class and resource. |

07 / WORKFLOW AND CHECKS

# From the brief to the final file

| **When Tim asks for…**                 | **Return…**                                                                                                                             |
|----------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------|
| **A plan**                             | A progression with the purpose of each section, support and independent check. Do not produce the final worksheet yet.                  |
| **Questions in full / questions only** | The actual pupil questions and necessary diagram specifications. Respect “questions only”; do not append an unsolicited planning essay. |
| **The resource**                       | The requested artifact, using the approved content. Do not create another approval gate when directly asked to produce it.              |
| **A revision**                         | The requested change, with unrelated approved content preserved. Check the complete revised file, not only the edited area.             |

Workflow shortcuts: PLAN → FINALISE → PRODUCE. Full templates and
command rules: Appendix A.

## Pre-delivery checks

| **Check**           | **Evidence to inspect**                                                                                                                                                                                                       |
|---------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Mathematics**     | Solve every question. Check signs, arithmetic, units, labels, rounding and any possible alternative answers. Verify distractors and worked examples.                                                                          |
| **Progression**     | The intended insights are represented. Entry questions are accessible for this class. Each substantial increase in demand is deliberate.                                                                                      |
| **Scaffolding**     | Support is present where needed, then fades. Independent questions remain possible without hidden hints or an adjacent worked pattern.                                                                                        |
| **Representations** | Grid scales, perpendicular heights, table entries and geometry labels agree with the task. Comparison pairs preserve the intended constants. Information and reminder cards use their section’s pale tint and remain legible. |
| **Layout**          | All text is legible at final size. Nothing clips, overlaps or collides. Working and drawing space match the expected solution.                                                                                                |
| **Consistency**     | Question numbering and content match across sheets, answers and projection. The correct front and back have been used. PDF corrections are rebuilt in source, never overlaid.                                                 |
| **Delivery**        | The actual final file opens, has the requested size, orientation and page count, and uses an accessible link to the file just checked.                                                                                        |

## Keep the pupil version and teacher thinking separate

Place rationales, anticipated misconceptions, answers and optional
discussion prompts in a separate teacher-facing section or file when
requested. Keep the pupil resource concise. An attractive page does not
by itself establish mathematical quality or classroom suitability.

## After teaching

Use feedback to identify whether the difficulty concerned prerequisites,
question choice, representation, support or page design. Record what
actually happened before suggesting an explanation. Update the relevant
example or rule only after distinguishing a local correction from a
transferable lesson.

APPENDIX A / RESOURCE CREATION WORKFLOW

# Three commands, one workflow

Stable template names: PLAN · FINALISE · PRODUCE

These shortcuts invoke the full templates on the following pages. Read
and execute the relevant template together with the applicable sections
of the current Guide; do not merely repeat the template. The shortcuts
supplement ordinary requests rather than replace them.

| **Template** | **Accepted commands (examples)**                                           | **Output and stopping point**                                                |
|--------------|----------------------------------------------------------------------------|------------------------------------------------------------------------------|
| **PLAN**     | PLAN; Plan; plan; Planning; PLANNING                                       | Teacher-facing progression. Stop before the final question set or worksheet. |
| **FINALISE** | FINALISE; Finalise; finalise; Finalise question set; FINALISE QUESTION SET | Exact pupil specification and clearly labelled non-printing notes. No PDF.   |
| **PRODUCE**  | PRODUCE; Produce; produce; Production; PRODUCTION                          | Create and check the resource from the latest finalised set.                 |

Command matching is case-insensitive. Uppercase PLAN, FINALISE and
PRODUCE are explicitly supported, as are the mixed-case and lowercase
versions above. Recognise a command when it requests an action,
including with a colon and an objective; do not trigger it when it is
merely quoted or discussed.

## Carry the resource forward, not unrelated assumptions

Use the current resource’s objective, code, class, prior teaching,
calculator expectations, format and latest agreed decisions. Explicit
current instructions and corrections override template defaults. Do not
transfer another class’s accessibility rules indiscriminately. If the
target resource or essential context is ambiguous, ask only for what is
missing.

A command completes one stage, not the whole sequence. PRODUCE
authorises production of the latest finalised question set and
subsequent corrections; do not add another approval gate. If that set or
a required template cannot be accessed, identify the missing material
instead of reconstructing it from guesses.

APPENDIX A / TEMPLATE: PLAN

# PLAN — Planning template

Input: objective and resource context. Output: teacher-facing
progression only.

Apply the following instructions to the current resource. Resolve
bracketed inputs from the user’s request and established context; they
are not text to print on the worksheet.

**Learning objective:** \[code — full learning objective\]

Plan a progression of questions for the requested resource. Unless the
current brief specifies otherwise, plan a double-sided A3 landscape
worksheet. Use the current Maths Resource Design Guide and the relevant
class context, prior teaching and accessibility decisions already
established for this resource.

Briefly identify the essential prerequisites, intended mathematical
insights and likely misconceptions. Keep the lesson focused on this
objective, distinguishing it from adjacent objectives already supplied.
Include a prerequisite check or bridge only where it is needed.

For each section, specify the proposed question content, its purpose,
what stays the same and changes, and which scaffolds are introduced,
retained or removed. Give enough detail about numbers, diagrams and task
types to evaluate the progression, without yet presenting the final
pupil wording.

Plan mathematical difficulty, representation changes and scaffold fading
separately. Use short, purposeful chains where comparison reveals useful
mathematics; reset to a familiar case when introducing a new idea. Do
not force minimally different questions onto every activity or remove
scaffolds at arbitrary question numbers.

For each purposeful comparison, identify what pupils should notice and,
where useful, a brief compare or predict prompt. Do not require a
written explanation after every question. Include a fresh independent
check without a neighbouring pattern that supplies the answer, and
appropriate depth for stronger pupils without unnecessary reading or
notation demands.

Where a relevant approved exemplar is available, inspect it and identify
the design features worth transferring. Use recorded examples and
non-examples to guide decisions, without copying topic-specific features
indiscriminately. If an exemplar is required but inaccessible, say so
rather than inventing its contents.

Propose a realistic quantity of questions and allocation across the
requested pages, allowing enough space for the working, writing, shading
or drawing pupils must actually do. Do not add questions merely to fill
the page or prescribe a fixed number of sections for every objective.

Use information already supplied, including calculator expectations.
State reasonable minor assumptions and flag only important unresolved
questions. Keep the rationale teacher-facing. Check the proposed
mathematics and the suitability of each transition before presenting the
plan.

| Stop after planning. Do not create the finalised question set or the worksheet yet. |
|-------------------------------------------------------------------------------------|

APPENDIX A / TEMPLATE: FINALISE

# FINALISE — Question-set template

Input: latest agreed plan and corrections. Output: exact content
specification, not a PDF.

Finalise the complete question set for \[code — current resource\],
using the latest agreed plan and the user’s subsequent corrections. Read
and apply the relevant sections of the current Maths Resource Design
Guide.

State exactly what pupils will read and complete: the numbered
questions, shared information, necessary reminders, any agreed worked
examples, and the precise scaffolding. Show which entries are supplied
and which are left blank. Do not leave the production stage to invent
question content or decide when support disappears.

Preserve the agreed progression and scope. Use concise wording
appropriate to this class and retain the established notation and
accessibility decisions. Do not change the mathematical task, add extra
questions or reintroduce rejected wording during finalisation.

Include all information needed for each experiment or context, such as
labels, units, equal likelihood, independence or replacement where
relevant. Make the scope of shared diagrams and information cards
explicit by giving the correct question references. Retain useful
reminders without giving away answers in independent checks.

Where a diagram or scaffold cannot be represented clearly in the
response, add a concise “Production note — not pupil text”, linked to
the relevant question or shared-information card. Specify the labels,
values, shading, pre-filled entries, blank parts and relationships
needed to construct it accurately. Do not use a written diagram
description as a replacement for the actual diagram on the pupil sheet.

Distinguish the exact pupil content from those non-printing construction
notes. Keep pedagogical rationale, anticipated misconceptions, teacher
answers and solutions to the pupil exercises out of this response.
Retain deliberately supplied worked examples, completed entries and
other agreed teaching material; these are not an unsolicited answer key.

Check every question mathematically, including examples and distractors.
Check wording, numbering, shared-question references, diagram
specifications, scaffold fading and any possible alternative answers.
Flag a substantive ambiguity or error rather than silently changing the
agreed task.

The result is the authoritative content specification for production,

# PRODUCE — Production template

Input: latest finalised specification and corrections. Output: checked
resource and download link.

Create the worksheet for \[code — current resource\] from the latest
finalised question set and the user’s subsequent corrections. Treat that
specification as authoritative: the earlier plan may inform layout
decisions, but it is not an alternative source from which to select
different questions.

Unless the current brief specifies otherwise, produce a two-page A3
landscape PDF suitable for double-sided printing, with narrow practical
margins and genuine vector text, mathematical notation, diagrams,
shading and borders. Apply any explicit alternative format instead of
imposing the worksheet default.

Use the current Maths Resource Design Guide. Match the established
resource style where applicable. Shared information, repeated data,
definitions and reminders must use a very pale tint of their surrounding
section’s colour, without question-number badges or prominent borders.
Keep each card close to the questions that need it.

Preserve the approved wording, numbering, mathematical content, diagram
information and scaffolding. Use non-printing production notes to
construct the resource; do not print those notes or teacher-facing
rationale. Do not expose exercise answers unless they are part of an
agreed worked example or supplied scaffold.

Use the full printable width and height. Allocate space according to the
working, writing, shading or drawing each task requires. Large blank
construction areas are useful space, not gaps to fill with text.
Maintain readable type and sufficient handwriting room, including the
vertical height of numerator and denominator boxes where specified.

Reflow rather than crowd the page or distort diagram geometry. Do not
add, omit or rewrite questions merely to make the layout fit. If
preserving the approved content and legibility requires a substantive
change, flag it rather than making that change silently.

For revisions, edit and regenerate the original source; never mask old
content with patches, replacement cards or overlays. If the source is
unavailable, reconstruct the affected section using native vector
elements and check it against the approved original. Preserve and verify
everything outside the requested changes. Retain the editable generation
source where available for future revisions.

Check the mathematics and compare the actual PDF against the finalised
set. Render and inspect both pages for legibility, alignment, overlaps,
clipping, diagram accuracy and usable working space. Verify page count,
page size and orientation, and that text and diagrams are not
rasterised. Report any unresolved issue; do not claim checks succeeded
when they did not.

For an A3 worksheet, save the final PDF as \[code\]\_\[full learning
objective\]\_A3.pdf. Use two-digit objective suffixes, such as SP2.07;
omit year-group labels and version information. Add \_Answers before
\_A3 only for a separately requested answer sheet. Use the supplied code
and adapt the format suffix if the requested format differs.
