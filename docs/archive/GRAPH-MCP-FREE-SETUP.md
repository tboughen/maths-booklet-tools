FREE CHATGPT GRAPH SETUP
Prepared 6 October 2026. Tim confirmed Add custom MCP server is available in
his ChatGPT account. He still needs to create a Render account. No service has
been deployed, and no account connection or live editor round trip is proven.

1. Create your own account at https://dashboard.render.com/register, using
   GitHub if convenient. Use the free workspace option and leave payment
   details unset. Do not upgrade. If your account is required to add billing
   details, stop and report that requirement rather than entering them.

2. Open the deployment link:
   https://render.com/deploy?repo=https%3A%2F%2Fgithub.com%2Ftboughen%2Fmaths-booklet-tools%2Ftree%2Fcodex%2Fchatgpt-graph-integration
   It uses the prepared review branch, whose root render.yaml describes only
   the graph service. If the button cannot locate the branch, use New >
   Blueprint in Render and choose:
     Repository: tboughen/maths-booklet-tools
     Branch: codex/chatgpt-graph-integration
     Blueprint path: render.yaml
   No website or question-bank deployment is part of this Blueprint.

3. Review the resources before deploying:
     Name: maths-booklet-graph-mcp (Render may append a unique suffix)
     Type: Web Service
     Runtime: Docker
     Plan: Free
     Region: Frankfurt
     Dockerfile: ./Dockerfile.graph-mcp
     Health check: /healthz
     Code auto-deploy: Off
     Database, disk, extra instances: None
   Deploy only if it lists a Free web service and no paid resources.
   DOWNLOAD_SIGNING_KEY is generated by Render; preserve it and keep it
   private. RENDER_EXTERNAL_URL is supplied automatically, so no hostname or
   signing key needs to be pasted into source or a chat.

4. Wait for the service to report Live. Copy its actual onrender.com URL.
   Open that URL with /healthz appended. Expect JSON with ok: true,
   rendererVersion: graph-1 and a buildId. Send only the public service URL
   back to Codex for HTTPS/tool/download verification. Never send credentials.
   Linux CI proves the image and maximum graph under 512 MiB; it does not
   prove this Render deployment, its actual speed or ChatGPT delivery.

5. Complete the normal website review/release first so the live human editor
   supports graph JSON and fragment imports. The existing website remains
   usable before release, but candidate editor links cannot be claimed to
   import until the website change is deployed and checked.

6. Follow GRAPH-MCP-CONNECTION.txt. In ChatGPT's Add custom MCP server use:
     Name: Maths Booklet Tools
     Description: Create printable coordinate graphs, points and straight lines.
     URL: <the actual service URL>/mcp
     Authentication: None
   Review the warning, create/install the plugin and select it with @ in a
   conversation. Check graph_capabilities, create_graph and revise_graph.
   Try: "Plot y = 2x + 1 on axes from -5 to 5."
   Verify the returned image, PNG/SVG/JSON files and editable website link,
   then ask for a revision. No separately billed OpenAI API calls are used
   by the renderer. Normal ChatGPT account permissions and usage still apply.

Free-tier behaviour
Render sleeps after 15 idle minutes and takes about a minute to wake. Open
<service URL>/healthz and wait for its JSON response before connecting; use
the same action if a first graph request times out, then retry once.
Do not set up keep-awake pings. The human website works even while the service
is asleep or suspended. Download links need the service; saved editable JSON
and website links continue to work independently once import support is live.
Without a payment method, exceeding included bandwidth suspends services and
exceeding build minutes disables new builds. The 750 monthly Free instance
hours are shared by the workspace. Actual cold-start and ChatGPT file-delivery
checks remain required. This is a free, quota-limited option, not always-on
hosting or an unlimited-use promise.
